Pick! Your Ticket, Picket.


## 📌 프로젝트 개요
픽켓은 사용자 친화적이고 신뢰할 수 있는 티켓 예매 웹사이트를 목표로 개발된 서비스입니다.  
콘서트, 공연, 이벤트 등 실시간 예매에 민감한 관람객들을 주요 대상으로 합니다.


## 👥 팀 역할
* 엄희연 : Frontend/Backend 담당
  - 회원가입/로그인/소셜 로그인
  - 예매 대기열 시스템
  - 결제 연동
  - 검색/알림 API
* 박지영 : Design/Publishing 담당
  - 브랜드 아이덴티티 디자인
  - UI/UX 설계
  - 반응형 웹 퍼블리싱


## 🚀 주요 기능

1. 회원 시스템
  - 휴대폰 본인인증 회원가입
  - 소셜 로그인 (카카오, 네이버, 구글)
  - 사용자 정보 관리

2. 게시판 시스템
  - 공지사항, 티켓오픈 안내
  - 게시글 작성/수정/삭제

3. 공연 등록 및 예매
  - 티켓셀러: 공연 등록/수정/삭제
  - 일반 사용자: 공연 예매, 좋아요, 리뷰

3-1. 접속자 대기열
  - Redis + WebFlux 기반 동시 접속 분산 처리
  - 대기 인원/예상 대기 시간 표시

3-2. 결제 시스템
  - 아임포트 연동
  - 예매 내역 조회/취소

4. 검색 시스템
  - 공연명, 아티스트, 장소 키워드 검색
  - 자동완성 기능

5. 알림 시스템
  - 공연별 알림 설정
  - 예매 완료, 티켓팅 당일 카카오 알림톡 발송


## 🛠 기술 스택

* Backend
  - Java, Spring Boot, Spring Security, WebFlux
  - Redis
  - MySQL (JPA/Hibernate)
  - 아임포트(I'mport) API
  - 카카오 알림톡 API
  - AWS

* Frontend
  - JavaScript/jQuery

* Design
  - Figma
  - PhotoShop
  - Illustrator
